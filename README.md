# Digital Public Safety

## Project Structure

| Folder | Purpose |
|--------|---------|
| `/data/currency/real` | Real currency images/data |
| `/data/currency/fake` | Counterfeit currency images/data |
| `/data/scam/transcripts` | Scam conversation transcripts |
| `/data/scam/control` | Control/non-scam conversation data |
| `/models/currency` | Currency detection models |
| `/models/scam` | Scam detection models |
| `/app` | Application code |
| `/docs` | Documentation |
